## 按问题查找

- **行业热度和分母**　先读国信两篇，再对照申万宏源的短窗做法与市场情绪日报的展示。
- **头部与扩散**　看主线看板、MarketBreadth 和国泰君安，分别核对成交、家数和相关性。
- **退出压力**　从 Amihud、MSCI、Stock Price Fragility 延伸到融资、ETF 和披露时点。
- **研究复核**　用 CNEquity 的迁移说明检查历史分类，用 Alphalens 与 Open Source Asset Pricing 对照样本和复现纪律。
