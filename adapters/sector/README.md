# 行业拥挤度导出

`python adapters/sector/sector_export.py input.json output.json`。输入含 `sectors`（稳定编号到当日行业分类名称）和 `sessions`（按真实交易日升序完整排列）。每个交易日提供 ISO 日期、带明确时区的 `available_at` 和 `stocks`。个股字段与 `factors.calculate.StockDay` 相同。成交额和滞后流通市值需采用相容单位。所有预期股票均需有行，缺值填 null。整日失采时保留日期，`stocks: null`。

导出复用原始因子函数，分别生成行业成交额份额 S、规模修正倍数 Q、个股成交偏离 D、上涨侧成交占比 U+。每项另计算 5 日均值相对此前最多 252 个交易日均值的历史分位，最少 200 个过去有效点。当前日期与缺失日期不进入过去有效样本。先按 5 日连续窗口计算，避免跨缺口拼接。原始值用比例或倍数，分位用 0–100。

改分类或改取样规则时创建独立历史段。只用首见且按日期无时间倒序的输入，旧日补录必须以真实入库时间另归档。导出值仅含行业汇总；原始成分和个股字段留在授权环境。冻结头部样本相关的 G/B 保留在原因子库，当前导出需要另建月末头部样本台账后才可覆盖它们。
